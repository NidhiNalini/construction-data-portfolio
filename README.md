# Construction Data Portfolio

Three connected analyses on Alberta construction project data,
progressing from raw data exploration to a relational database
to a domain-specific safety outcomes study.

## Projects

### 01 — Alberta Construction EDA
Identified 3 data quality issues in raw Alberta construction 
records. Built a reproducible cleaning pipeline with documented 
findings on project costs, sectors, and regions.

### 02 — Construction Data Warehouse
Normalised the flat CSV into a 3-table relational schema with 
enforced constraints. Built a Python-SQL query pipeline for 
aggregations and cross-table analysis.

### 03 — Safety Outcomes Analysis
Analysed how sector and region affect construction safety 
outcomes in Alberta. Identified high-risk segments using SQL 
aggregations and visualisations across 5 dimensions.
